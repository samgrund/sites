Chapter 1: Orbital Mechanics

An Interactive Introduction to Celestial Motion

1.1 Gravitational Acceleration

The gravitational acceleration experienced by an object near a massive body is given by Newton's law of universal gravitation. At Earth's surface, we feel this as the familiar force that keeps us grounded. The acceleration due to gravity is calculated as:

g = G × M / r²

Where G is the gravitational constant, M is the mass of the central body, and r is the distance from its center. Let's compute this for Earth: 

# Physical constants
G = 6.67430e-11  # Gravitational constant (m³/kg/s²)
M_earth = 5.972e24  # Earth's mass (kg)
R_earth = 6.371e6  # Earth's radius (m)

# Calculate surface gravity
g = G * M_earth / R_earth**2

print(f"Gravitational acceleration at Earth's surface:")
print(f"g = {g:.4f} m/s²")

As expected, we get approximately 9.81 m/s², the value you've likely memorized! But gravity varies with altitude — astronauts on the International Space Station experience only about 90% of surface gravity.

1.2 Orbital Period

Kepler's third law relates the orbital period T to the semi-major axis a of an orbit:

T = 2π √(a³ / (G × M))

Notice how we'll reuse the variables G and M_earth that we defined in the previous code block — demonstrating persistent state: 

import numpy as np

# Define orbital altitude (ISS orbits at ~400 km)
altitude = 400e3  # meters above surface
a = R_earth + altitude  # Semi-major axis

# Calculate orbital period using Kepler's third law
T = 2 * np.pi * np.sqrt(a**3 / (G * M_earth))

# Convert to minutes
T_minutes = T / 60

print(f"Orbital parameters for altitude = {altitude/1000:.0f} km:")
print(f"Semi-major axis: {a/1000:.1f} km")
print(f"Orbital period: {T:.1f} seconds")
print(f"               = {T_minutes:.1f} minutes")
print(f"\nThe ISS completes ~{24*60/T_minutes:.1f} orbits per day!")

The International Space Station orbits Earth approximately every 90 minutes, giving astronauts the remarkable experience of witnessing 16 sunrises and sunsets each day!

1.3 Visualizing Orbital Trajectories

Orbits aren't always circular. Johannes Kepler discovered that planetary orbits are ellipses, characterized by their eccentricity e:

  • e = 0: Perfect circle
  • 0 < e < 1: Ellipse
  • e = 1: Parabola (escape trajectory)

Let's visualize an elliptical orbit using the polar equation:

r(θ) = a(1 - e²) / (1 + e·cos(θ)) 
import matplotlib.pyplot as plt
# Orbital parameters
a = 1.5e8  # Semi-major axis (km)
e = 0.5    # Eccentricity

# Generate orbit path
theta = np.linspace(0, 2*np.pi, 500)
r = a * (1 - e**2) / (1 + e * np.cos(theta))

# Convert to Cartesian coordinates
x = r * np.cos(theta)
y = r * np.sin(theta)

# Create the plot
fig, ax = plt.subplots()
ax.plot(x, y, 'b-', linewidth=2, label=f'Orbit (e={e})')
ax.plot(0, 0, 'yo', markersize=20, label='Central body (Star)')
ax.set_xlabel('x (km)', fontsize=12)
ax.set_ylabel('y (km)', fontsize=12)
ax.set_title('Elliptical Orbit', fontsize=14, fontweight='bold')
ax.set_aspect('equal')
ax.grid(True, alpha=0.3)
ax.legend()
plt.tight_layout()
plt.show()

Chapter 2: Escape Velocity

Breaking Free from Gravitational Wells

2.1 The Concept of Escape

Escape velocity is the minimum speed an object needs to escape a celestial body's gravitational influence without further propulsion. It's derived by equating kinetic energy with gravitational potential energy:

vesc = √(2GM/r)

Let's calculate escape velocities for various bodies in our solar system: 

import matplotlib.pyplot as plt
import numpy as np

# Gravitational constant
G = 6.67430e-11  # m³/kg/s²

# Celestial body data: (name, mass in kg, radius in m)
bodies = [
    ("Earth", 5.972e24, 6.371e6),
    ("Moon", 7.342e22, 1.737e6),
    ("Mars", 6.417e23, 3.390e6),
    ("Jupiter", 1.898e27, 6.991e7),
    ("Sun", 1.989e30, 6.957e8),
]

print("Escape Velocities in the Solar System")
print("=" * 45)
print(f"{'Body':<12} {'Mass (kg)':<12} {'v_esc (km/s)':<12}")
print("-" * 45)

escape_velocities = {}
for name, mass, radius in bodies:
    v_esc = np.sqrt(2 * G * mass / radius)
    escape_velocities[name] = v_esc
    print(f"{name:<12} {mass:.2e}    {v_esc/1000:.2f}")
🚀 Practical Implications

Earth's escape velocity of ~11.2 km/s is why rocket launches require such enormous amounts of fuel. The Moon's low escape velocity (2.4 km/s) made the Apollo return trips much easier than leaving Earth!

2.3 Escape Velocity vs. Altitude

Escape velocity decreases as you move away from a planet's surface. This is why spacecraft often use multi-stage rockets — each stage operates at a different altitude where the required velocity is lower. 

import matplotlib.pyplot as plt

# Escape velocity as a function of altitude

altitudes = np.linspace(0, 50000e3, 500)  # 0 to 50,000 km

                fontsize=9, ha='left')

ax.set_xlabel('Altitude (thousands of km)', fontsize=12)

Chapter 3: Planetary Atmospheres

Why Some Worlds Have Air and Others Don't

3.1 Atmospheric Retention

Whether a planet can retain an atmosphere depends on the competition between thermal velocity of gas molecules and the planet's escape velocity. If molecules move fast enough, they escape into space.

The thermal velocity of gas molecules follows the Maxwell-Boltzmann distribution. The root-mean-square velocity is:

vrms = √(3kT/m)

Where k is Boltzmann's constant, T is temperature, and m is molecular mass. 

import numpy as np

# Constants
k_B = 1.380649e-23  # Boltzmann constant (J/K)
u = 1.66054e-27     # Atomic mass unit (kg)

# Gas molecules: (name, molecular mass in u)
gases = {
    'H₂ (Hydrogen)': 2,
    'He (Helium)': 4,
    'H₂O (Water)': 18,
    'N₂ (Nitrogen)': 28,
    'O₂ (Oxygen)': 32,
    'CO₂ (Carbon dioxide)': 44,
}

# Temperature range (100K to 1000K)
T = 288  # Earth's average surface temperature (K)

print(f"Thermal velocities at T = {T} K (Earth's surface)")
print("=" * 50)
print(f"{'Gas':<25} {'Mass (u)':<10} {'v_rms (m/s)':<12}")
print("-" * 50)

v_thermal = {}
for gas, mass in gases.items():
    m = mass * u  # Convert to kg
    v_rms = np.sqrt(3 * k_B * T / m)
    v_thermal[gas] = v_rms
    print(f"{gas:<25} {mass:<10} {v_rms:.0f}")

print(f"\nEarth's escape velocity: 11,186 m/s")
print("Gases with v_rms << v_esc are retained.")

3.2 The Jeans Escape Parameter

A useful criterion is that a planet retains a gas if its escape velocity is at least 6 times the thermal velocity (the "Jeans escape" criterion). Let's visualize which planets can retain which gases: 

import matplotlib.pyplot as plt
import numpy as np

# Planet data: (name, escape_vel m/s, surface_temp K)
planets = {
    'Mercury': (4250, 440),
    'Venus': (10360, 737),
    'Earth': (11186, 288),
    'Moon': (2380, 250),
    'Mars': (5030, 210),
    'Titan': (2640, 94),
    'Jupiter': (59500, 165),
}

fig, ax = plt.subplots()

# Plot each gas as a line (v_thermal vs T)
T_range = np.linspace(50, 800, 100)
colors = plt.cm.viridis(np.linspace(0, 1, len(gases)))

for (gas, mass), color in zip(gases.items(), colors):
    m = mass * u
    v_rms = np.sqrt(3 * k_B * T_range / m)
    ax.plot(T_range, v_rms, '-', color=color, linewidth=2, label=gas)

# Plot each planet as a point (T, v_esc/6)
for planet, (v_esc, T) in planets.items():
    # Planet retains gas if v_esc/6 > v_thermal
    ax.scatter(T, v_esc/6, s=150, zorder=5, edgecolors='black', linewidth=2)
    ax.annotate(planet, (T, v_esc/6), xytext=(5, 5), textcoords='offset points', fontsize=9)

ax.set_xlabel('Temperature (K)', fontsize=12)
ax.set_ylabel('Velocity (m/s)', fontsize=12)
ax.set_title('Atmospheric Retention: Gases vs. Planets\n(Planets retain gases below their marker)', 
             fontsize=13, fontweight='bold')
ax.legend()
ax.set_xlim(50, 800)
ax.set_ylim(0, 12000)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

print("Planets can retain gases whose thermal velocity curves fall BELOW their marker.")
🌍 Why Earth Has No Hydrogen Atmosphere

Earth's marker on the plot is above the H₂ and He curves, meaning these light gases escape to space. That's why our atmosphere is dominated by N₂ and O₂, which are heavy enough to be retained. Jupiter, with its massive gravity, retains even hydrogen — hence its thick hydrogen-helium atmosphere!

Chapter 4: Stellar Luminosity

The Power Output of Stars

4.1 The Stefan-Boltzmann Law

Stars radiate energy as blackbodies. The total power output (luminosity) of a star depends on its surface temperature and size according to the Stefan-Boltzmann law:

L = 4πR²σT⁴

Where σ = 5.67 × 10⁻⁸ W/m²/K⁴ is the Stefan-Boltzmann constant. Notice the fourth power dependence on temperature — a small increase in temperature dramatically increases luminosity! 

import numpy as np

# Constants
sigma = 5.670374e-8  # Stefan-Boltzmann constant (W/m²/K⁴)
L_sun = 3.828e26     # Solar luminosity (W)
R_sun = 6.957e8      # Solar radius (m)
T_sun = 5778         # Solar effective temperature (K)

def stellar_luminosity(R, T):
    """Calculate luminosity given radius and temperature."""
    return 4 * np.pi * R**2 * sigma * T**4

# Verify with the Sun
L_calc = stellar_luminosity(R_sun, T_sun)

print("Stefan-Boltzmann Law Verification")
print("=" * 40)
print(f"Solar radius: {R_sun:.3e} m")
print(f"Solar temperature: {T_sun} K")
print(f"Calculated luminosity: {L_calc:.3e} W")
print(f"Actual solar luminosity: {L_sun:.3e} W")
print(f"Agreement: {L_calc/L_sun * 100:.1f}%")

Chapter 5: The Hertzsprung-Russell Diagram

Mapping the Stars

5.1 Introduction

The Hertzsprung-Russell (H-R) diagram is one of the most important tools in stellar astronomy. It plots stars according to their luminosity versus surface temperature (or spectral type), revealing distinct populations and evolutionary stages.

Most stars fall along the main sequence, a diagonal band where hydrogen fusion powers the star. Giants, supergiants, and white dwarfs occupy distinct regions representing different evolutionary stages.

5.2 Building an H-R Diagram

# Generate synthetic stellar data
np.random.seed(42)

# Main sequence stars (most common)
n_ms = 200
T_ms = 10**(np.random.uniform(3.5, 4.5, n_ms))  # 3000 - 30000 K
# L ∝ T^4 for main sequence (roughly)
L_ms = (T_ms / 5778)**4 * np.random.lognormal(0, 0.3, n_ms)

# Red giants
n_rg = 40
T_rg = 10**(np.random.uniform(3.5, 3.7, n_rg))  # 3000-5000 K
L_rg = 10**(np.random.uniform(1.5, 3, n_rg))    # 30-1000 L_sun

# Supergiants
n_sg = 15
T_sg = 10**(np.random.uniform(3.5, 4.3, n_sg))
L_sg = 10**(np.random.uniform(3.5, 5, n_sg))

# White dwarfs
n_wd = 30
T_wd = 10**(np.random.uniform(3.9, 4.5, n_wd))  # Hot but dim
L_wd = 10**(np.random.uniform(-3, -1, n_wd))

# Create the H-R diagram
fig, ax = plt.subplots()

ax.scatter(T_ms, L_ms, c='#3498db', s=20, alpha=0.6, label='Main Sequence')
ax.scatter(T_rg, L_rg, c='#e74c3c', s=50, alpha=0.7, label='Red Giants')
ax.scatter(T_sg, L_sg, c='#f39c12', s=100, marker='*', label='Supergiants')
ax.scatter(T_wd, L_wd, c='#9b59b6', s=30, alpha=0.7, label='White Dwarfs')

# Add the Sun
ax.scatter([5778], [1], c='yellow', s=200, edgecolors='black', 
           linewidth=2, zorder=10, label='Sun')

# Formatting
ax.set_xlabel('Surface Temperature (K)', fontsize=12)

5.3 Stellar Evolution on the H-R Diagram

A star's position on the H-R diagram changes as it evolves. Let's trace the evolutionary track of a Sun-like star: 


import numpy as np

Chapter 6: Working with Astropy Units

Dimensional Analysis Made Easy

6.1 Introduction to Astropy Units

One of the most common sources of errors in scientific calculations is unit mismatches. The Astropy library provides a powerful units and quantities system that tracks physical units automatically, performs unit conversions, and catches dimensional errors before they cause problems.

Let's start by importing the units module and exploring how to create quantities: 

from astropy import units as u
from astropy import constants as const

# Creating quantities with units
distance = 384400 * u.km          # Distance to the Moon
speed = 299792458 * u.m / u.s     # Speed of light
mass = 5.972e24 * u.kg            # Earth's mass

print("🌙 Basic Quantities with Units")
print("=" * 45)
print(f"Distance to Moon: {distance}")
print(f"Speed of light:   {speed}")
print(f"Earth's mass:     {mass:.3e}")

# Unit conversions are automatic!
print(f"\n📐 Unit Conversions")
print("=" * 45)
print(f"Moon distance in au: {distance.to(u.au):.5f}")
print(f"Speed of light in km/h: {speed.to(u.km/u.hour):.2e}")
print(f"Earth's mass in solar masses: {mass.to(u.M_sun):.2e}")
💡 Why Use Units?

The Mars Climate Orbiter was lost in 1999 because one team used imperial units while another used metric. Astropy's unit system prevents such errors by making units explicit and conversions automatic.

6.3 Calculations with Automatic Unit Handling

The real power of Astropy units becomes apparent when performing calculations. Units combine and cancel automatically, and the result carries the correct units: 

import numpy as np
from astropy import units as u
from astropy import constants as const

print("🚀 Escape Velocity Calculation")
print("=" * 50)

# Calculate escape velocity: v_esc = sqrt(2GM/R)
v_esc_earth = np.sqrt(2 * const.G * const.M_earth / const.R_earth)

print(f"\nRaw result: {v_esc_earth}")
print(f"Simplified: {v_esc_earth.decompose()}")
print(f"In km/s:    {v_esc_earth.to(u.km/u.s):.2f}")

# Compare multiple bodies
print("\n" + "=" * 50)
print("Escape Velocities Across the Solar System")
print("=" * 50)

bodies = [
    ("Earth", const.M_earth, const.R_earth),
    ("Moon", 7.342e22 * u.kg, 1737.4 * u.km),
    ("Mars", 6.417e23 * u.kg, 3389.5 * u.km),
    ("Jupiter", const.M_jup, const.R_jup),
    ("Sun", const.M_sun, const.R_sun),
]

print(f"{'Body':<10} {'Mass':<20} {'v_esc (km/s)':>15}")

6.4 Equivalencies: Converting Between Different Physical Quantities

Astropy supports equivalencies — special conversions between physically related but dimensionally different quantities. For example, wavelength and frequency are related through the speed of light: 

from astropy import units as u

print("🌈 Spectral Equivalencies")
print("=" * 55)

# Wavelength of hydrogen-alpha line
H_alpha = 656.28 * u.nm

print(f"Hydrogen-alpha wavelength: {H_alpha}")

# Convert to frequency using spectral equivalency
freq = H_alpha.to(u.THz, equivalencies=u.spectral())
print(f"Frequency: {freq:.2f}")

# Convert to energy
energy = H_alpha.to(u.eV, equivalencies=u.spectral())
print(f"Photon energy: {energy:.3f}")

# Convert to wavenumber (used in spectroscopy)
wavenumber = H_alpha.to(1/u.cm, equivalencies=u.spectral())
print(f"Wavenumber: {wavenumber:.0f}")

print("\n" + "=" * 55)
print("Common Spectral Lines")
print("=" * 55)

lines = [
    ("Lyman-alpha (UV)", 121.567 * u.nm),
    ("H-alpha (Red)", 656.28 * u.nm),
    ("Sodium D (Yellow)", 589.3 * u.nm),
    ("21-cm Hydrogen", 21 * u.cm),
    ("CO J=1-0 (Radio)", 2.6 * u.mm),
]

print(f"{'Line':<20} {'Wavelength':<15} {'Frequency':<15} {'Energy':>12}")
print("-" * 65)
for name, wavelength in lines:
    freq = wavelength.to(u.GHz, equivalencies=u.spectral())

6.5 Dimensional Analysis and Error Catching

One of the most valuable features is automatic detection of unit errors. Astropy will raise an exception if you try to add incompatible units: 

from astropy import units as u
import numpy as np

print("✅ Valid Operations")
print("=" * 45)

# Adding same dimensions works
d1 = 100 * u.km
d2 = 50000 * u.m
print(f"{d1} + {d2} = {d1 + d2}")

# Multiplying different units creates compound units
force = 10 * u.kg * 9.8 * u.m / u.s**2
print(f"Force: {force}")
print(f"In Newtons: {force.to(u.N)}")

print("\n❌ Invalid Operations (will raise error)")
print("=" * 45)

try:
    # This will fail - can't add distance to time!
    result = 5 * u.km + 3 * u.s
except u.UnitConversionError as e:
    print(f"Error caught: {type(e).__name__}")
    print(f"Message: Cannot add km and s (incompatible units)")

try:
    # This will fail - can't compare mass to length!
    comparison = (5 * u.kg) > (3 * u.m)
except u.UnitConversionError as e:
    print(f"\nError caught: {type(e).__name__}")
    print(f"Message: Cannot compare kg and m (incompatible units)")

print("\n✓ Unit checking prevents silent errors in calculations!")

6.6 Practical Example: Stellar Parameters

Let's put it all together with a comprehensive stellar calculation that demonstrates the power of unit-aware computing: 

import numpy as np
from astropy import units as u
from astropy import constants as const

def stellar_analysis(name, radius, temperature, distance):
    """Perform comprehensive stellar analysis with proper units."""
    
    print(f"\n{'='*60}")
    print(f"⭐ STELLAR ANALYSIS: {name}")
    print(f"{'='*60}")
    
    # Input parameters
    print(f"\n📊 Input Parameters:")
    print(f"   Radius:      {radius.to(u.R_sun):.2f}")
    print(f"   Temperature: {temperature}")
    print(f"   Distance:    {distance.to(u.pc):.1f} = {distance.to(u.lyr):.1f}")
    
    # Luminosity (Stefan-Boltzmann law)
    L = 4 * np.pi * radius**2 * const.sigma_sb * temperature**4
    L_solar = L.to(u.L_sun)
    
    print(f"\n💡 Luminosity:")
    print(f"   L = 4πR²σT⁴")
    print(f"   L = {L.to(u.W):.3e}")
    print(f"   L = {L_solar:.2f}")
    
    # Absolute magnitude
    M_sun = 4.83  # Sun's absolute magnitude
    M_abs = M_sun - 2.5 * np.log10(L_solar.value)
    
    # Apparent magnitude
    m_app = M_abs + 5 * np.log10(distance.to(u.pc).value / 10)
    
    print(f"\n🔭 Magnitudes:")
    print(f"   Absolute magnitude: {M_abs:.2f}")
    print(f"   Apparent magnitude: {m_app:.2f}")
    
    # Peak wavelength (Wien's law)
    lambda_peak = const.b_wien / temperature
    
    print(f"\n🌈 Peak Emission:")
    print(f"   λ_peak = b/T")
    print(f"   λ_peak = {lambda_peak.to(u.nm):.1f}")
    
    # Classify by peak wavelength
    peak_nm = lambda_peak.to(u.nm).value
    if peak_nm < 400:
        color = "Ultraviolet (Blue-white star)"
    elif peak_nm < 500:
        color = "Blue-Violet"
    elif peak_nm < 570:
        color = "Green-Yellow (like the Sun)"
    elif peak_nm < 620:
        color = "Orange"
    else:
        color = "Red"
    print(f"   Color: {color}")
    
    # Flux at Earth
    flux = L / (4 * np.pi * distance**2)
    
    print(f"\n📡 Flux at Earth:")
    print(f"   F = L / (4πd²)")
    print(f"   F = {flux.to(u.W/u.m**2):.3e}")
    
    return {
        'luminosity': L_solar,
        'abs_mag': M_abs,
        'app_mag': m_app,
        'peak_wavelength': lambda_peak.to(u.nm)
    }

# Analyze some famous stars
stars = [
    ("Sun", 1 * u.R_sun, 5778 * u.K, 1 * u.AU),
    ("Sirius A", 1.711 * u.R_sun, 9940 * u.K, 8.6 * u.lyr),
    ("Betelgeuse", 764 * u.R_sun, 3500 * u.K, 700 * u.lyr),
    ("Proxima Centauri", 0.154 * u.R_sun, 3042 * u.K, 4.246 * u.lyr),
]

results = []
for star_data in stars:
    result = stellar_analysis(*star_data)
    results.append((star_data[0], result))

# Summary table
print(f"\n\n{'='*70}")
print("📋 SUMMARY TABLE")
print(f"{'='*70}")
print(f"{'Star':<18} {'L (L☉)':<12} {'M_abs':<10} {'m_app':<10} {'λ_peak (nm)':>12}")
print("-"*70)
for name, r in results:
    print(f"{name:<18} {r['luminosity'].value:<12.2f} {r['abs_mag']:<10.2f} {r['app_mag']:<10.2f} {r['peak_wavelength'].value:>12.0f}")
🎯 Key Takeaways

Astropy's unit system provides: (1) automatic unit tracking and conversion, (2) built-in astronomical constants with uncertainties, (3) spectral and other physical equivalencies, and (4) error detection for dimensional mistakes. Using units consistently makes your code more readable, reliable, and reproducible.

Quick Reference Formulas

# Useful astrophysical formulas as functions
import numpy as np

G = 6.67430e-11
sigma = 5.670374e-8
k_B = 1.380649e-23

def escape_velocity(M, R):
    """Escape velocity (m/s) given mass (kg) and radius (m)"""
    return np.sqrt(2 * G * M / R)

def orbital_period(a, M):
    """Orbital period (s) given semi-major axis (m) and central mass (kg)"""
    return 2 * np.pi * np.sqrt(a**3 / (G * M))

def luminosity(R, T):
    """Stellar luminosity (W) given radius (m) and temperature (K)"""
    return 4 * np.pi * R**2 * sigma * T**4

def thermal_velocity(T, m):
    """RMS thermal velocity (m/s) given temperature (K) and mass (kg)"""
    return np.sqrt(3 * k_B * T / m)

def schwarzschild_radius(M):
    """Schwarzschild radius (m) for a black hole of mass M (kg)"""
    c = 299792458
    return 2 * G * M / c**2

# Demo calculations

R_sun = 6.957e8

print(f"Earth's orbital period: {orbital_period(1.496e11, M_sun)/86400:.2f} days")
print(f"Sun's surface escape velocity: {escape_velocity(M_sun, R_sun)/1000:.1f} km/s")
