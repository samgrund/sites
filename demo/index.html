🌍 Orbital Mechanics

An Interactive Introduction to Celestial Motion

1. Gravitational Acceleration

The gravitational acceleration experienced by an object near a massive body is given by Newton's law of universal gravitation. At Earth's surface, we feel this as the familiar force that keeps us grounded. The acceleration due to gravity is calculated as:

g = G × M / r²

Where G is the gravitational constant, M is the mass of the central body, and r is the distance from its center. Let's compute this for Earth: 

# Physical constants
G = 6.67430e-11  # Gravitational constant (m³/kg/s²)
M_earth = 5.972e24  # Earth's mass (kg)
R_earth = 6.371e6  # Earth's radius (m)

# Calculate surface gravity
g = G * M_earth / R_earth**2

print(f"Gravitational acceleration at Earth's surface:")
print(f"g = {g:.4f} m/s²")

As expected, we get approximately 9.81 m/s², the value you've likely memorized! But gravity varies with altitude — astronauts on the International Space Station experience only about 90% of surface gravity.

2. Orbital Period

Kepler's third law relates the orbital period T to the semi-major axis a of an orbit. For a satellite orbiting Earth, we can derive the period from our previously defined constants:

T = 2π √(a³ / (G × M))

Notice how we'll reuse the variables G and M_earth that we defined in the previous code block — demonstrating persistent state: 

import numpy as np

# Define orbital altitude (ISS orbits at ~400 km)
altitude = 400e3  # meters above surface
a = R_earth + altitude  # Semi-major axis

# Calculate orbital period using Kepler's third law
T = 2 * np.pi * np.sqrt(a**3 / (G * M_earth))

# Convert to minutes
T_minutes = T / 60

print(f"Orbital parameters for altitude = {altitude/1000:.0f} km:")
print(f"Semi-major axis: {a/1000:.1f} km")
print(f"Orbital period: {T:.1f} seconds")
print(f"               = {T_minutes:.1f} minutes")
print(f"\nThe ISS completes ~{24*60/T_minutes:.1f} orbits per day!")

The International Space Station orbits Earth approximately every 90 minutes, giving astronauts the remarkable experience of witnessing 16 sunrises and sunsets each day!

3. Visualizing Orbital Trajectories

Orbits aren't always circular. Johannes Kepler discovered that planetary orbits are ellipses, characterized by their eccentricity e:

  • e = 0: Perfect circle
  • 0 < e < 1: Ellipse
  • e = 1: Parabola (escape trajectory)

Let's visualize an elliptical orbit. The shape is described in polar coordinates by r(θ) = a(1 - e²) / (1 + e·cos(θ)): 

import matplotlib.pyplot as plt

# Orbital parameters
a = 1.5e8  # Semi-major axis (km) - roughly Earth-Sun distance
e = 0.5    # Eccentricity (elliptical orbit)

# Generate orbit path
theta = np.linspace(0, 2*np.pi, 500)
r = a * (1 - e**2) / (1 + e * np.cos(theta))

# Convert to Cartesian coordinates
x = r * np.cos(theta)
y = r * np.sin(theta)

# Create the plot
fig, ax = plt.subplots(figsize=(8, 8))
ax.plot(x, y, 'b-', linewidth=2, label=f'Orbit (e={e})')
ax.plot(0, 0, 'yo', markersize=20, label='Central body (Star)')
ax.set_xlabel('x (km)', fontsize=12)
ax.set_ylabel('y (km)', fontsize=12)
ax.set_title('Elliptical Orbit', fontsize=14, fontweight='bold')
ax.set_aspect('equal')
ax.grid(True, alpha=0.3)
ax.legend(loc='upper right')
plt.tight_layout()
plt.show()

The yellow dot represents the central body (like our Sun), located at one focus of the ellipse. Notice how the orbit comes closer to the star at one point (perihelion) and farther at the opposite point (aphelion).

4. Interactive Exploration

Now let's explore how eccentricity affects orbital shape interactively. Use the slider below to change the eccentricity and watch the orbit transform from circular to highly elliptical: 

# This cell updates when you move the slider above!
# The variable 'eccentricity' is injected from the slider

# Use slider value (injected by JavaScript)
e_interactive = eccentricity  # This variable is set by the slider

# Generate orbit with current eccentricity
theta = np.linspace(0, 2*np.pi, 500)
a_interactive = 100  # Normalized semi-major axis

# Handle edge case for very high eccentricity
if e_interactive >= 0.99:
    e_interactive = 0.99

r = a_interactive * (1 - e_interactive**2) / (1 + e_interactive * np.cos(theta))
x = r * np.cos(theta)
y = r * np.sin(theta)

# Calculate key orbital parameters
periapsis = a_interactive * (1 - e_interactive)
apoapsis = a_interactive * (1 + e_interactive)

# Create visualization
fig, ax = plt.subplots(figsize=(8, 6))
ax.plot(x, y, 'b-', linewidth=2.5)
ax.plot(0, 0, 'yo', markersize=15, label='Central Body', zorder=5)

# Mark periapsis and apoapsis
ax.plot(periapsis, 0, 'go', markersize=10, label=f'Periapsis: {periapsis:.1f}')
ax.plot(-apoapsis, 0, 'ro', markersize=10, label=f'Apoapsis: {apoapsis:.1f}')

ax.set_xlim(-250, 150)
ax.set_ylim(-150, 150)
ax.set_xlabel('x (normalized units)', fontsize=11)
ax.set_ylabel('y (normalized units)', fontsize=11)
ax.set_title(f'Orbital Shape — Eccentricity e = {e_interactive:.2f}', 
             fontsize=13, fontweight='bold')
ax.set_aspect('equal')
ax.grid(True, alpha=0.3)
ax.legend(loc='upper left', fontsize=9)
ax.axhline(y=0, color='gray', linestyle='--', alpha=0.3)
ax.axvline(x=0, color='gray', linestyle='--', alpha=0.3)

plt.tight_layout()
plt.show()

print(f"Eccentricity: {e_interactive:.2f}")
print(f"Closest approach (periapsis): {periapsis:.1f} units")
print(f"Farthest point (apoapsis): {apoapsis:.1f} units")
print(f"Ratio (apoapsis/periapsis): {apoapsis/periapsis:.2f}x")

As you increase eccentricity toward 1, the orbit becomes increasingly elongated. At e = 0, you have a perfect circle where periapsis equals apoapsis. At high eccentricities, the orbiting body spends most of its time far from the central mass, then whips around quickly during close approach — this is why comets are only visible for short periods!
